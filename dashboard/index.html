04Execution time

How long each run took

Seconds per run, from Rhombus's log timestamps. Every run is a dot; the box shows the middle half of a case's runs when it has three or more.

Most runs take 14–29 s. The slow ones (68–104 s) are when Rhombus writes a step's code: they're the hollow dots above the break: the first baseline run, and runs right after a chatbot fix.
