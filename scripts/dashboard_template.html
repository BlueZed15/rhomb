04Execution time

How long each run took

Seconds per run, from Rhombus's log timestamps. Every run is a dot; the box shows the middle half of a case's runs when it has three or more.

Drift runs take 5–27 s. The hollow dots at the top are the first run after a build (138 s and 153 s), when Rhombus writes each step's code. schema-drift1 and schema-drift2 only logged start times.

Every number here comes from the repo. Runs are in rhombus-runs.csv, repeat outputs in consistency.csv and validator verdicts in results/. The diff tool loads datasets/ and the downloaded GCS outputs. The heat map is my rating per case, each linked to its write-up. The page is built by build_dashboard.py.
